Get the zcrDRM Windows agent

The Windows agent gives your team right-click file protection, a hardened viewer for .drmx files, and OS-level screen-capture blocking. Install once on each Windows machine that needs to protect or open DRM files.

zcrdrm-agent-v1.6.1-win-x64.zip

1.7 MB · Windows 10 build 19041+ or Windows 11 · x64

Download for Windows (v1.6.1)

System requirements

Windows 10 build 19041+ or Windows 11 (for the screen-capture protection — older Windows builds still install but fall back to a slightly weaker capture-blocker).
  • .NET 10 Desktop Runtime (x64) — download from Microsoft
  • ~50 MB free disk space
  • Admin privileges to register file associations (one-time)

Install in 3 steps

  1. Extract the zip to C:\Program Files\EnterpriseDRM\ (or anywhere)
  2. Register file associations Open PowerShell as Admin, run register-shell-integration.ps1 with -TrayPath and -ViewerPath
  3. Configure server URL Set environment variable DRM_SERVER_URL=https://drm.zcr.ai and your tenant ID

Detailed walkthrough including screen-capture verification: install guide on GitHub ↗

What you get after install

  • Right-click file → "Protect with DRM" — encrypts the file in place and registers it with your tenant
  • Double-click .drmx — opens in the hardened viewer with the policy's watermark overlay
  • Tray icon — agent status, policy refresh, restart shortcut
  • Screen-capture protection — Print Screen, Snipping Tool, OBS, Teams / Zoom / Meet screen-share all return a black rectangle for the viewer window (Windows 10 19041+)
