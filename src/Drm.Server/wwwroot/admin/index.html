Format

            
Transparent-encryption files

          

          
        


        
Transparent files keep their original extension (.xlsx stays .xlsx) by appending a tamper-evident DRM trailer. They open in their native application; DRM-aware tools surface tenant + policy metadata.

Format

            
Secure containers

          

          
        


        
A secure container (.drmcontainer) seals an entire folder tree behind a single AES-GCM key. Files inside keep their relative paths and can cross-reference each other (e.g. Illustrator → linked Photoshop assets).

Folder watcher service

          

          
        


        
The DRM Folder Watcher Windows Service runs on a file server, watches the listed folders, and appends a DRM transparent-encryption trailer to every newly saved file. Configure the service host via appsettings.json in Drm.FolderWatcher.Service.
